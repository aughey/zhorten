# zhorten-app

`zhorten-app` is the browser application for zhorten. It is a Leptos client-side rendered app that compiles to WebAssembly and talks to the server through same-origin JSON endpoints.

## Responsibilities

- Render the public home page and the private administration console.
- Call `/api/login`, `/api/logout`, and the authenticated `/api/links` endpoints from the browser.
- Display dashboard data, create and delete short links, copy short URLs, and render QR codes.
- Share API request and response types with the server through `zhorten-core`.

## Rendering Model

This crate is built with the `csr` feature by default. The production browser bundle is generated by compiling the library for `wasm32-unknown-unknown` with `--features csr`, then running `wasm-bindgen` over the resulting `.wasm` file.

There is no server-side rendering or hydration boundary in this crate. The Axum server serves `index.html`, static assets, and the generated WASM bundle; once loaded, the Leptos app owns the UI in the browser.

Code that requires browser APIs is gated behind `#[cfg(feature = "csr")]`. This keeps the component tree type-checkable for non-CSR builds while ensuring fetch, clipboard, location, date formatting, and startup mounting are only compiled for the browser.

## Important Files

- `src/lib.rs` contains the Leptos components, browser API helper, QR rendering, and WASM start function.
- `../../public/index.html` is the static HTML shell served by `zhorten-server`.
- `../../public/assets/` contains shared browser assets such as CSS, bootstrap JavaScript, and the favicon.

## Build

From the workspace root:

```bash
cargo build --locked --package zhorten-app --lib --release \
  --target-dir target/front \
  --target wasm32-unknown-unknown \
  --no-default-features \
  --features csr

wasm-bindgen \
  --target web \
  --out-dir target/site/assets/pkg \
  --out-name zhorten_app \
  target/front/wasm32-unknown-unknown/release/zhorten_app.wasm
```
